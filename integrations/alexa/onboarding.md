# Onboarding : enceintes Amazon Echo (Alexa)

1. Prévenir la personne : interface non officielle d'Amazon, qui peut casser ; Moli apparaîtra
   comme un appareil « Moli » de son compte Amazon.
2. Déclarer `kind = "alexa"` avec `domain` (le site Amazon du compte) ; `moli-os check-config`,
   redémarrer. Le pilote attend la connexion (« Connecte le compte Amazon… »).
3. La personne connecte le compte depuis le tableau de bord (Système, carte Alexa) : page Amazon,
   connexion, adresse de la dernière page collée. Jamais son mot de passe ailleurs que chez Amazon.
4. Tester : les Echo et les groupes apparaissent ; « mets du jazz dans le salon » joue ; le volume
   suit ; une annonce passe.
